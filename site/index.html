Schnellstart

In 3 Schritten starten.

Keine Konfigurationsdatei, kein Terminal. In einer Minute weißt du, wie es deinem Server geht.

  1. Pulo laden

    Lade Pulo herunter und zieh die App in deinen Programme-Ordner. Du brauchst macOS 27 oder neuer.

  2. Server eintragen

    Gib die Adresse deines Servers ein, zum Beispiel localhost:3000, und starte die Prüfung.

  3. Buddy im Blick behalten

    Pulo zeigt dir den Status in Klartext. Läuft etwas schief, siehst du es an seiner Mimik.

FAQ

Kurz gefragt.

Was ist Pulo?

Pulo ist eine macOS-App, die prüft, ob dein lokaler Server erreichbar ist, und dir den Status in Klartext zeigt. Der gleichnamige Buddy zeigt dir mit seiner Mimik, wie es deinem Server geht.

Ist Pulo kostenlos?

Ja, es gibt eine kostenlose Version. Mit Pro bekommst du zusätzliche Funktionen – die Details findest du oben im Vergleich.

Welche macOS-Version brauche ich?

Pulo läuft ab macOS 27.

Gibt es Pulo für Windows?

Noch nicht. Eine Windows-Version steht ganz oben auf der Roadmap – trag dich dort in die Warteliste ein.

Wie steht es um den Datenschutz?

Pulo prüft deine lokalen Server direkt von deinem Mac aus. Alle Details zu Konto und Daten findest du in der Datenschutzerklärung.

Welche Daten verlassen meinen Mac?

Die Prüfungen deiner Server laufen lokal auf deinem Mac. Nur wenn du Pro kaufst, wird der Kauf über den App Store abgewickelt – dafür gelten die Datenschutzregeln von Apple.

Bereit für deinen neuen Buddy?

Pulo laden, Server prüfen, entspannt weiterarbeiten.
